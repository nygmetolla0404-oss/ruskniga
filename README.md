# 3D Литературный портал: от книги к жизни
**3D Әдеби портал: кітаптан өмірге**

Автор: Тасбалта Аяулым Шәріпбайқызы, учитель русского языка и литературы, магистр, педагог-модератор, КГУ «ООШ имени Жамбыла», Казыгуртский район, Туркестанская область.

## Что внутри
- **Сказочный 3D-остров «Адал азамат»**: 6 регионов-ценностей (Единство и согласие · Трудолюбие и профессионализм · Созидание и инновации · Справедливость и ответственность · Закон и порядок · Независимость и патриотизм). В центре — озеро и Книга-портал, между регионами — реки.
- **36 волшебных книг**: в каждом регионе 3 произведения русской и 3 — казахской литературы (сказки, басни, рассказы, Пушкин, Толстой, Крылов, Абай, Ауэзов, Алтынсарин, Валиханов, Жамбыл, Момышұлы, Есенберлин и др.).
- **Гиды**: снежный барс **Ақбарыс** ведёт по земле, беркут **Қыран** — по небу. Управление: W A S D / стрелки, Shift — бег, Пробел / C — вверх / вниз, E — войти. На телефоне — экранные кнопки.
- **3D-мир каждой книги**: сказочные дома (избы для русских книг, юрты для казахских), 3D-герои, музей с предметами и фото, кинотеатр с буктрейлером, почтовый ящик с письмом, камни-задания, достопримечательность, машина времени с погодой эпохи.
- **3D-книга (эффект AR)** с 7 вкладками: Сюжет · Герои · Музей · Трейлер · Письмо · Задания · Гид.
  - **Чтение**: тест по тексту + техника чтения (микрофон сравнивает чтение с текстом, считает точность и слова в минуту).
  - **Письмо**: ответ герою с чек-листом (обращение, объём, слово-ценность, вопрос, подпись, оформление) и ответным письмом героя.
  - **Говорение**: устный ответ через микрофон и диалог с гидом.
  - **От книги к жизни**: жизненная ситуация с последствиями выбора и рефлексия.
- **Озвучка нейроголосами**: русский — Светлана и Дмитрий, казахский — Айгүл и Даулет (более 2000 фраз).
- Разделы: Книги, Машина времени, Музей, Ценности, игры «Адал азамат», Педагогическая идея (по Положению конкурса, с аннотацией на двух языках и планом TEDx на 7 минут), Автор.

## Как открыть
- **Двойной щелчок по `index.html`** — сайт работает (нужен интернет только для библиотеки three.js и шрифтов).
- Микрофон (задания на чтение и говорение) работает в Chrome и Edge; на сайте в интернете — по адресу https.

## Публикация (GitHub Pages)
Загрузите в репозиторий всё, кроме папки `tools/`, затем Settings → Pages → Branch `main` → Save.

## Как редактировать
| Что | Файл |
|---|---|
| Регионы, жизненные ситуации, игры, подписи к фото | `js/data.js` |
| Книги регионов 1–6 | `js/books-1.js` … `js/books-6.js` |
| Музейные предметы, фразы гида, машина времени | `js/extra.js` |
| Тексты интерфейса, педагогическая идея, автор | `js/i18n.js` |
| Фото автора | `assets/img/author.jpg` |

**После изменения текстов обновите озвучку** (macOS, нужны `pip install edge-tts` и `ffmpeg`):
```
osascript -l JavaScript tools/collect_clips.js "$(pwd)"
python3 tools/make_audio.py tools/clips.json
```
Готовые записи пропускаются, новые — дописываются в `assets/audio/` и `js/audio-map.js`. Фразы, для которых нет записи (например, ответы гида на текст ученика), читает голос браузера.
